# 뉴스레터 추출 에셋

PDF 내부에서 추출한 이미지입니다.

| 파일 | 용도 |
|---|---|
| `people-hero-background.png` | PEOPLE 메인 배경 사진 |
| `people-subject-cutout.png` | PEOPLE 메인 인물 투명 누끼 |
| `people-subject-mask.png` | 인물 누끼 마스크 |
| `replay-public-phone-photo.png` | RE:PLAY 배경 사진 |
| `logo-dark.png` | 밝은 배경용 재단 로고 |
| `logo-light.png` | 어두운 배경용 재단 로고 |
| `news-scholarship-image.png` | 장학·수상 뉴스 이미지 |
| `news-multicultural-image.png` | 다문화 여성 뉴스 이미지 |
| `news-book-image.png` | 책 소개 뉴스 이미지 |
| `news-consulting-image.png` | 협력·상담 뉴스 이미지 |

`pdf-image-*` 파일은 PDF 원본 이미지와 마스크를 보존한 중간 추출물입니다.
